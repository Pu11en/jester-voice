Progress after this original checklist is recorded in `sim/STATUS.md`; several gaps below have since been fixed or tested.

September 28, 2026. Drew approved the conversation examples and asked to make Jester usable. This is the working checklist for discovering missing behavior. A green unit test is evidence only for the layer it exercises. Each gate needs a specific failed or passing observation before real project work starts.

## Discovery loop

For each capability, start with Drew's exact examples, then add paraphrases, pauses, corrections, ambiguous targets, API failures, restarts and duplicate audio. Run the same fixture through the actual decision code with fake EBI and assert both what happened and what **did not** happen. Then test the unmocked audio and EBI boundaries separately, finish with one controlled live Discord round trip, and turn every real miss into a permanent replay case. Keep owner/guest authority and zero-write checks in every action family. Report unknowns as unknowns; passing fake fixtures cannot establish real-room reliability.
